# Design history

Throwaway prototypes and notes from designing the board. They use mock data and aren't part of the plugin. Open any HTML file directly in a browser.

| File | What it explored |
|---|---|
| `prototype-layouts.html` | Four structurally different layouts (`?variant=A..D`): three-pane, flow board, next-move feed, atlas map |
| `prototype-atlas-draft.html` | The first merged design (parchment "atlas" look), kept as a draft |
| `prototype-themes.html` | The four shipped themes (Swiss, Terminal, Transit, Toybox) on one feature set, plus the theme picker |
| `feature-notes.md` | How mattpocock/skills store state, the next-move rules, and the feature list (written while the project was still called "Cockpit") |

The design context for UI work lives in `/.impeccable.md`.
