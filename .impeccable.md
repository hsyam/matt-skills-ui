## Design Context

- **Product**: Matt Skills UI, a local web UI started by a slash command that visualises and drives mattpocock/skills work: specs, tickets, wayfinder maps, triage, artifacts and agent sessions.
- **Audience**: a solo or small-team engineer running Claude Code with Matt Pocock's skills. They have the browser open next to the terminal for hours.
- **Jobs**: see the dependency graph and frontier; know the next command for any item; dispatch agents; answer agent questions; check setup health.
- **Tone**: four shipped themes the user picks between (Swiss, Terminal, Transit, Toybox; see skills/matt-skills-ui/web/style.css). Each changes layout and how the graph is drawn, not just colours. An earlier parchment "atlas" look was rejected and is kept as a draft in docs/design/prototype-atlas-draft.html.
- **Chosen by the user**: the feature set of prototype A (nav, graph, inspector, session dock) and the swimlane board of prototype B. Features approved.
- **Avoid**: dark neon dashboards, glassmorphism, left-border accent cards, identical card grids, Inter.
